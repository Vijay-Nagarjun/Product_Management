# Product Management Portfolio

This repository contains my product management portfolio — product teardowns, PRDs, and case studies, based on public app reviews and market research.

Each project below is shown in a condensed, resume-ready format. The full versions — with complete RICE prioritization tables, detailed validation methodology, persona sourcing, and edge-case analysis — run longer and are available on request; I kept them separate so the linked versions stay quick to read.

> **Note on formats:** Most projects are shared as Markdown for quick scanning on GitHub. The Jar teardown is shared as a PDF instead, to preserve its in-app screenshots — Markdown doesn't render those cleanly.
